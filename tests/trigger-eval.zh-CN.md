# 触发评估

检查助手是否在 Outlook 日历任务中加载本 skill。例如，在已选择 Outlook 的对话中问“明天有哪些安排”，预期加载；问“帮我写封邮件”则预期不加载。

## 运行方法

需要支持 skill 的助手，并已安装完整项目目录。每条提示在全新会话中原样输入，观察是否加载 [SKILL.md](../SKILL.md)。只评估加载行为时使用模拟工具，避免实际日历写入。

未指定产品的正例先提供“用户已选择 Outlook 日历”的上下文。逐条记录期望、实际加载情况及会话依据。修改 skill 描述前后可分别运行，对比触发范围。

## 记录结果

目标是 12 个正例全部触发、6 个反例全部不触发。可在 `.local-calendar-test/trigger-results.md` 手工记录日期、助手版本、用例编号、实际加载情况和失败依据；该目录需自行创建，已被 Git 忽略。此评估通过会话执行，没有自动生成报告的命令。

出现误触发或漏触发时，根据实际上下文检查能力与适用范围描述，再重跑受影响用例。
