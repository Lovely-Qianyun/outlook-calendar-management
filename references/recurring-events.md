# 定期日程

## 先理解：一次 vs 整个系列

一个定期日程由三部分组成：

| 概念 | 是什么 | 你什么时候会看到它 |
|------|--------|--------------------|
| **主事件** | 整个系列（含规则） | `read` 时输出 🆕 系列主事件ID；`list` 不直接显示 |
| **某一次**（occurrence） | 系列中的一次实例 | `list` 里每行一个，标记 🔁(系列) |
| **单独改过的那次**（例外） | 被单独修改/取消的一次 | `list` 标记 🔁(已修改) / 🔁(已取消) |

**核心规则**：对"某一次"做修改/删除/移动 → 只影响这次；要改规则、删整个系列 → 必须操作**主事件**（`read` 输出里的 🆕 系列主事件ID）。

## 支持的规则写法（`--repeat "..."`）

| 你想要 | 写法 |
|--------|------|
| 每天 | `每天`（或 `每2天`、`每N天`） |
| 每周某天 | `每周五`（或 `每2周周三`；只写 `每周` 默认从开始那天算） |
| 每个工作日 | `工作日`（周一至周五） |
| 每月某日 | `每月15日` |
| 每月第 N 个周几 | `每月第一个周三` / `每月最后一个周五` |
| 每年某月某日 | `每年9月21日` |

结束条件（配合 `--repeat`）：
- `--repeat-until 2026-12-31`：到这天为止
- `--repeat-times 5`：一共 5 次

## 常见操作

| 想做什么 | 怎么做 |
|---------|--------|
| 改某一次的时间（只改这次） | `update <那次ID> --start ... --end ...`（会创建"例外"，其余不变） |
| 删某一次（只删这次） | `delete <那次ID>` → 选 [1] 仅删本次 |
| 改整个系列的规则 | `read` 拿 🆕 系列主事件ID → `update <主ID> --repeat "新规则"` |
| 解除定期（变单次） | `update <主ID> --repeat ""` |
| 删整个系列 | `delete <主ID>`（会警告）或 `delete <那次ID> --series` |
| 下次什么时候 | `next <那次ID或主ID>` |
| 把整个系列挪几天 | `move <主ID> --days N`（有警告） |

## 需要注意

- **改整个系列的规则会重置**之前单独改过/删过的某几次（有警告，先提醒用户）
- 把某一次改到**跨越相邻一次**的时间会被拒绝（"相邻出现冲突"）——调整到不早于前一次、不晚于后一次
- 已删除的某一次**不可再访问**（报"不存在"），重新 `list` 确认即可
- 写不出来的规则会**友好报错**，不会悄悄创建错的：比如 `每3小时`、`每N个工作日`（这类不支持）
